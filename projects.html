02

State Estimation & Robust Flight Control

Linux JSBSim State Estimation & Robust Flight Control

Explore Full Project →

Python and JSBSim Based Flight Dynamics, State Estimation, and Robust Control

Developed a nonlinear flight dynamics, state estimation, and control simulation environment on Linux using Python and JSBSim. The project evaluates modern GNC architectures against a nonlinear C172 aircraft model while accounting for sensor noise, actuator nonlinearities, and changes in flight operating condition.

A steady flight reference condition was trimmed and linearized to construct a reduced longitudinal state space model. LQR state feedback and Kalman state estimation were combined into an LQG architecture, followed by LQG/LTR and H-infinity robust control comparisons using nonlinear operating point and Monte Carlo validation.

Technical Areas

Linux • Python • JSBSim • Flight Dynamics • State Space • Trim & Linearization • Controllability • Observability • Kalman Filtering • LQR • LQG • LQG/LTR • H-infinity Control • Monte Carlo Analysis

Project Objectives

  • Establish and validate steady flight trim conditions using the nonlinear JSBSim aircraft model.
  • Develop a reduced longitudinal state space representation from a numerical aircraft linearization.
  • Evaluate controllability and observability of the reduced flight dynamics model.
  • Design LQR state feedback and Kalman state estimation for closed-loop flight regulation.
  • Integrate the controller and estimator into an LQG output feedback architecture.
  • Characterize nonlinear elevator actuator behavior and incorporate actuator compensation into the closed-loop simulation.
  • Extend the design using LQG/LTR and H-infinity robust control methods.
  • Validate controller performance across changing operating conditions and paired nonlinear Monte Carlo simulations.
