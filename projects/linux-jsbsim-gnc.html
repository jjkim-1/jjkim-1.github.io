Guidance, Navigation & Control Portfolio Project

Linux JSBSim State Estimation & Robust Flight Control

A Python and Linux based flight dynamics and control project using JSBSim to evaluate state estimation, optimal control, actuator nonlinearities, robust control, and nonlinear closed-loop performance. The project progresses from aircraft trim and longitudinal linearization through LQR, Kalman state estimation, LQG, LQG/LTR, H-infinity control, and Monte Carlo robustness analysis.

Engineering Overview

Key Technical Components

Nonlinear Plant

JSBSim C172

Nonlinear aircraft dynamics are simulated in JSBSim and evaluated about trimmed steady flight conditions across multiple airspeeds and altitudes.

State Estimation

Kalman LQE

A state estimator reconstructs the reduced longitudinal state from noisy airspeed, pitch-rate, and pitch-attitude measurements.

Control

LQG / LTR / H∞

Optimal output-feedback and robust dynamic controllers are evaluated using the same nonlinear aircraft and actuator environment.

Robustness

50 Paired Cases

Paired Monte Carlo testing varies airspeed, altitude, pitch disturbance, and sensor-noise realizations while preserving identical test conditions between controllers.

Development Approach

From Flight Model to Robust Control

01

Trim & Linearization

Established a steady flight reference condition and extracted a reduced longitudinal state-space representation from the nonlinear JSBSim model.

02

LQR & Actuator Analysis

Designed state feedback and characterized nonlinear elevator hysteresis before developing compensation for closed-loop implementation.

03

LQE & LQG

Integrated Kalman state estimation with LQR feedback to create an output-feedback controller using simulated sensor measurements.

04

Robust Control

Extended the controller study to LQG/LTR and dynamic H-infinity synthesis, followed by nonlinear operating-point and Monte Carlo comparison.

Nonlinear Validation

Controller Performance & Robustness

The final analysis compares LQG/LTR and H-infinity control using nonlinear JSBSim simulations, multiple operating points, and paired Monte Carlo cases.

Design Insight

Robustness Trade Study

The final comparison demonstrates that robust controller synthesis does not automatically guarantee superior nonlinear implementation when actuator dynamics and control activity are included.

Engineering Takeaway

What This Project Demonstrates

This project demonstrates a complete controls workflow implemented in a Linux development environment: nonlinear flight simulation, trim and linearization, controllability and observability analysis, state estimation, optimal control, actuator characterization, robust control synthesis, operating-point testing, and Monte Carlo validation. The final controller comparison also highlights the importance of validating linear control designs against nonlinear vehicle and actuator behavior rather than relying only on nominal state-space performance.
